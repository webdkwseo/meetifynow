# MeetifyNow — Backlog priorytetów

## P0
- utworzenie wydarzenia,
- udział bez logowania,
- prosty i szybki grid zaznaczania dostępności,
- wybór finalnego terminu,
- e-mail invites i confirmations,
- podstawowa integracja Google Calendar,
- obsługa stref czasowych,
- podstawowe template’y spotkań.

## P1
- workspace,
- role użytkowników,
- Outlook sync,
- branding i customizacja,
- przypomnienia,
- dashboard z czasem odpowiedzi,
- widget embed.

## P2
- Slack integration,
- CRM sync,
- recurring meetings,
- shared team availability,
- required participants rules,
- podstawowe smart suggestions.

## P3
- AI-generated follow-up,
- analytics porównawcze dla zespołów,
- scoring ryzyka frekwencji,
- branch-specific optimization packs.

## Twarda zasada priorytetyzacji
Każdy element backlogu musi odpowiadać na jedno z pytań:
1. Czy przyspiesza domknięcie terminu?
2. Czy obniża koszt koordynacji?
3. Czy zwiększa retencję zespołu B2B?
4. Czy podnosi gotowość do płatności?
Jeśli nie, trafia poza roadmapę.
