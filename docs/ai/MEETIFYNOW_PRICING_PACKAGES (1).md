# MeetifyNow — Pakiety i monetyzacja

## Zasada
Monetyzujemy workflow i oszczędność czasu, nie samą możliwość zaznaczenia dostępności.

## Pakiety
### Free
- 0 PLN
- podstawowe ankiety terminów,
- udział bez logowania,
- ograniczona liczba aktywnych wydarzeń,
- branding MeetifyNow,
- brak zaawansowanych integracji.

### Starter
- 49–79 PLN / użytkownik / miesiąc
- dla freelancerów i mikrozespołów,
- Google Calendar,
- podstawowe przypomnienia,
- podstawowe szablony spotkań,
- brak zaawansowanego workflow zespołowego.

### Growth
- 149–199 PLN / workspace / miesiąc lub per user po walidacji
- główny plan dla małych agencji i software house,
- współdzielone workflow,
- Outlook + Google,
- branding firmy,
- dashboard efektywności,
- role w zespole,
- podstawowe inteligentne rekomendacje.

### Pro
- 399–599 PLN / miesiąc
- CRM sync,
- Slack actions,
- zaawansowane reguły,
- AI assistance,
- zaawansowana analityka,
- priorytetowe wsparcie.

## Zasady cenowe
- Free ma napędzać aktywację i virality.
- Growth ma być pierwszym planem z realnym ROI dla ICP.
- Pro ma monetyzować integracje i analitykę, a nie kosmetyczne dodatki.
- Należy testować, czy lepiej działa billing per user, per workspace czy hybrydowy.
